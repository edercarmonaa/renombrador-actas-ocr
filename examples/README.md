# Datos de ejemplo

Esta carpeta contiene archivos ficticios para documentar la estructura esperada
por el script sin publicar informacion personal real.

El archivo `datos_ejemplo.xlsx` usa las columnas que el programa consume:

- Columna B: nombre de quien entrega.
- Columna E: fecha de baja.
- Columna F: nombre final del PDF.

Los PDFs de entrada no se incluyen porque en el uso real son documentos
escaneados con informacion laboral. Mantenerlos fuera del repositorio evita
publicar datos personales o documentos administrativos.
